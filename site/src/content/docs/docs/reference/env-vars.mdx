Every environment variable the control plane, schedulers, runtime manager, in-VM harness and dashboard read, grouped by service, with its default and what it does. **Required in prod** means the process refuses to start (or, for the harness, refuses to run the workload) when `LANTERN_ENV` is `prod`, `production` or `staging` and the value is missing. Flag values accept `1`, `true` or `on` unless a row says otherwise.

## How to use this page

Local development needs none of these: `make run-api` sets the database, Redis and S3 values, and every security variable has a dev default or is skipped with a warning. For production, start from the [checklist below](#production-checklist), then see [Operations](/lantern/docs/operate/operations/) for how the Helm chart supplies them. A production process that is missing a required value logs it by name and exits at startup.

## Production checklist

| Service | Must be set |
| --- | --- |
| Control plane | `JWT_SECRET`, `LANTERN_RECEIPT_SECRET`, `LANTERN_CREDENTIAL_KEY`, `LANTERN_GRPC_SERVICE_TOKEN`, `LANTERN_RLS_ENFORCE=1` with `LANTERN_APP_DB_PASSWORD`, `LANTERN_CONTROL_PLANE_TLS_CERT`/`_KEY`, `LANTERN_SCHEDULER_GRPC_ADDR`, `LANTERN_RUNTIME_MANAGER_TLS_CA`/`_CERT`/`_KEY` |
| Runtime scheduler | `LANTERN_GRPC_SERVICE_TOKEN`, `SCHEDULER_NODE_TOKEN`, `LANTERN_DEFAULT_MANAGER_ADDR`, manager TLS CA and client cert |
| Runtime manager | `LANTERN_GRPC_SERVICE_TOKEN`, `LANTERN_MANAGER_TLS_CA`/`_CERT`/`_KEY` |
| Harness | `LANTERN_WORKLOAD_UID`, `LANTERN_HARNESS_EXEC_TOKEN` |

The control plane also refuses to start in prod with `LANTERN_TWILIO_WEBHOOK_AUTH=off` or `LANTERN_USE_CLAUDE_CODE=1`, and the scheduler refuses `LANTERN_DIALER=stub`.

## Control plane: auth, secrets, trust boundaries

These are the production-required ones. With `LANTERN_ENV=production` the control plane refuses to start when a required value is missing.

| Variable | Default | Meaning |
| --- | --- | --- |
| `JWT_SECRET` | dev default (public) | Signs dashboard JWTs. Unset or the dev default is fatal in prod. **Required in prod.** |
| `LANTERN_RECEIPT_SECRET` | dev default | HMAC secret for run receipts and marketplace invocation signatures. Fatal in prod when unset. **Required in prod.** |
| `LANTERN_RECEIPT_ED25519_SEED` | unset | Seed for the Ed25519 receipt key. Unset: receipts fall back to HMAC and cannot be verified offline by third parties. |
| `LANTERN_CREDENTIAL_KEY` | unset (plaintext in dev) | 32-byte AES-256-GCM key that encrypts provider keys and connector tokens at rest. Fatal in prod when unset or malformed. **Required in prod.** |
| `LANTERN_GRPC_SERVICE_TOKEN` | unset | Shared service token for the gRPC trust boundaries. Set the same value on the control plane, gateway, workflow engine, runtime scheduler, model router and runtime manager. Fatal in prod when unset; dev warns and allows unauthenticated calls. **Required in prod.** |
| `LANTERN_CONTROL_PLANE_TLS_CERT` | unset | PEM path for the gRPC server certificate. Both cert and key, or neither; one alone is always fatal. Prod requires them. **Required in prod.** |
| `LANTERN_CONTROL_PLANE_TLS_KEY` | unset | PEM path for the matching key. **Required in prod.** |
| `LANTERN_RLS_ENFORCE` | unset (off) | `1` enforces Postgres row-level security through the `lantern_app` pool. Prod refuses to start without it. **Required in prod.** |
| `LANTERN_APP_DB_PASSWORD` | unset | Password of the non-superuser `lantern_app` role used when RLS is enforced. Prod refuses to start without it. **Required in prod.** |
| `LANTERN_AUTHZ_ENFORCE` | off | `1`/`true`/`on`: a key missing the endpoint's scope gets 403. Off: the miss is logged and the request proceeds. |
| `LANTERN_CORS_ORIGINS` | `http://localhost:3001` | Comma-separated allowed browser origins. Public endpoints (receipt verify, `/.well-known/*`) stay open. |
| `LANTERN_TRUSTED_PROXIES` | empty | CIDRs whose `X-Forwarded-For` is trusted for rate-limit keys. |
| `LANTERN_RUNTIME_SECRET_TOKEN` | unset | Pre-shared token for the manager-to-control-plane secret relay. Unset: `POST /v1/runtime/secrets/resolve` returns 403. |
| `LANTERN_AGENT_IDENTITY_SECRET` | unset | HMAC secret for per-instance agent identity tokens. |
| `LANTERN_AGENT_IDENTITY_ED25519_SEED` | unset | Seed for Ed25519 agent identity tokens (preferred over the HMAC secret). |
| `LANTERN_AGENT_IDENTITY_TTL` | `1h` | Identity token lifetime (Go duration). |
| `LANTERN_DL_SIGNING_SECRET` | unset | Signing secret for short-lived document download links. |
| `LANTERN_SIGNAL_TOKEN` | unset | Shared secret for `/v1/signals` (header `x-lantern-signal-token`). Unset: the endpoint is 401. |
| `SLACK_SIGNING_SECRET` | unset | Verifies Slack slash commands. Unset in prod: unsigned commands are refused. |
| `LANTERN_TWILIO_WEBHOOK_AUTH` | on | `off` skips Twilio signature checks. Fatal in prod. |
| `LANTERN_USE_CLAUDE_CODE` | unset | `1` routes through a local `claude` binary. Fatal in prod. |
| `LANTERN_CLAUDE_BINARY` | found on PATH | Explicit path to that binary. |

## How this list was built

Names and defaults come from the reads in code, not from other docs: Go `os.Getenv` and the local `envOrDefault`/`envInt` helpers in `services/control-plane`, `services/scheduler` and `services/runtime-scheduler`; Rust `std::env::var` in `services/runtime-manager/src` and `services/harness/src`; `process.env` in `apps/web`. Prod requirements come from the startup guards (`runStartupGuards` in the control plane, `authz.rs`/`tls.rs` in the manager).

## Limits

- Not covered yet: the workflow engine, model router, gateway, surface gateway and the two chat bridges. The service token above applies to the first three.
- Rows whose default says *set at spawn* or *from spawn.json* are written by the manager. Setting them yourself on the harness is overridden or ignored.
- Duration values are Go durations (`30s`, `1h`) unless the name ends in `_SECS`, `_MS`, `_MIN` or `_DAYS`.
- Defaults for the model-tier variables change with releases; check `services/control-plane/internal/handlers/llm_proxy.go`.
