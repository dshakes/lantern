<Steps>

1. **Boot the stack** (Docker for Postgres, Redis and MinIO; the API and dashboard run on the host):

   ```bash
   pal dev                 # API :8080, dashboard :3001, logs in one terminal
   pal dev --infra-only    # just the containers, if you run the API yourself
   ```

2. **Scaffold an agent.** Templates: `basic` (default), `research`, `tool-use`, `connector`, `personal`, `scheduled`, `approval`.

   ```bash
   pal init my-agent --template research
   ```

   <FileTree>
   - my-agent/
     - agent.yaml  name, model, system prompt, optional workflow
     - …           starter code for the template
   </FileTree>

3. **Start the inner loop** and keep it running while you edit:

   ```bash
   cd my-agent
   pal agent dev my-agent --input '{"prompt":"hi"}' --eval
   ```

   On every change to `agent.yaml` or a `.yaml`, `.ts`, `.py`, `.js` or `.json` file it:
   1. publishes a new agent version,
   2. fires a smoke run with `--input`,
   3. streams `step_started`, `step_completed`, `step_failed` and `confidence_evaluated` as a waterfall,
   4. with `--eval`, runs the agent's eval suite and prints pass/fail against the baseline.

   Ctrl-C exits. (`agents` and `agent` are the same command.)

4. **Gate it like CI will:**

   ```bash
   pal test --agent my-agent --suite factual-accuracy          # non-zero exit on regression
   pal test --agent my-agent --rehearse --window 24h          # replay recent real failures
   ```

</Steps>

<details>
<summary>What is running, and where</summary>

| Piece | Port | Notes |
| --- | --- | --- |
| Control-plane API | `:8080` | REST, SSE and health. `:50051` is its gRPC port. |
| Dashboard | `:3001` | Next.js dev server. |
| Postgres / Redis / MinIO | `:5432` / `:6379` / `:9000` | Docker containers. |

`pal dev logs [service]` tails container logs; `pal dev down` stops them (`--volumes` also deletes data). Full list: [Installation](/docs/start/installation/).

</details>

<Aside type="tip" title="Real microVMs on a Mac">
Runs in the inner loop use the shared tier by default. To exercise the microVM tier locally, see [Run real microVMs on your Mac](/docs/runtime/local-microvms/).
</Aside>

When the loop is green, [deploy it](/docs/start/deploy/).
