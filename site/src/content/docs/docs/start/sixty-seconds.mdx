You need Git, Docker and Go 1.25+ for the CLI. The first `docker compose` build pulls and builds images, which takes a few minutes once; after that every command here is seconds.

```bash
git clone https://github.com/dshakes/lantern.git pal && cd pal
( cd packages/cli && go build -o "$(go env GOPATH)/bin/pal" ./cmd/lantern )
```

<Tabs>
<TabItem label="1. No key: the demo">

<Steps>

1. Start the self-contained demo. It answers from recorded replays, so no API key is needed.

   ```bash
   pal demo
   ```

2. It opens `http://localhost:3001/kiosk`. You get a private workspace with sample agents; it is deleted after 30 minutes.

3. Stop it with `pal demo --down`.

</Steps>

More: [Demo mode](/docs/start/demo/).

</TabItem>
<TabItem label="2. Your key: your agent">

<Steps>

1. Boot the local stack (Postgres, Redis, MinIO, API on `:8080`, dashboard on `:3001`):

   ```bash
   pal dev
   ```

2. In a second terminal, describe the agent in one sentence. PAL designs it, test-calls your key, creates it and streams the first run:

   ```bash
   pal onboard --yes --provider anthropic --api-key "$ANTHROPIC_API_KEY" \
     --description "Turn meeting notes into a summary with action items"
   ```

3. Run it again any time:

   ```bash
   pal runs create --agent <name-it-printed> --input '{"notes":"..."}' --stream
   ```

</Steps>

Prefer clicking? The same flow is at [localhost:3001/onboarding](http://localhost:3001/onboarding). More: [Build your first agent](/docs/start/quickstart/).

</TabItem>
<TabItem label="3. From your code">

With the stack from tab 2 running and an API key from **Settings → API keys**:

<Tabs syncKey="lang">
<TabItem label="TypeScript" icon="seti:typescript">
```ts
import { LanternClient } from "@lantern/sdk";

const client = new LanternClient({ baseUrl: "http://localhost:8080", apiKey: process.env.PAL_API_KEY });
const run = await client.runs.create({ agent: "my-agent", input: { notes: "..." } });
for await (const e of client.runs.events(run.id)) console.log(e.kind);
```
</TabItem>
<TabItem label="Python" icon="seti:python">
```python
from lantern import LanternClient

async with LanternClient(base_url="http://localhost:8080") as client:
    run = await client.runs.create(agent="my-agent", input={"notes": "..."})
    async for e in client.runs.events(run.id):
        print(e)
```
</TabItem>
<TabItem label="Go" icon="seti:go">
```go
c := lantern.New(lantern.WithBaseURL("http://localhost:8080"))
r, err := c.CreateRun(ctx, lantern.RunOptions{AgentName: "my-agent", Input: map[string]string{"notes": "..."}})
```
</TabItem>
<TabItem label="curl" icon="seti:shell">
```bash
curl -s -X POST localhost:8080/v1/runs -H "Authorization: Bearer $PAL_API_KEY" \
  -d '{"agentName":"my-agent","input":{"notes":"..."}}'
```
</TabItem>
</Tabs>

Install notes for each SDK: [SDKs](/docs/sdks/).

</TabItem>
</Tabs>
