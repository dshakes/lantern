## Agents that act are easy to start and hard to trust.

## It brings you what matters. It waits on what is risky.

pal runs on your Mac next to iMessage and WhatsApp. Ordinary replies go out in your voice, paced like you. <p class="kicker">PAL Runtime · for builders</p>

## The parts every production agent needs.

pal is built on PAL Runtime, and your agents get the same platform. Every step is **journaled**, so a crash resumes instead of restarting. Budgets are checked **before** the model is called, so a hard cap costs nothing. Untrusted code runs in a **microVM** with an egress allowlist, and models are addressed by capability, not by vendor name.

## From a checkout to a first result.

Every path starts from a checkout. [Install](/docs/start/installation/) lists the prerequisites (Docker, Node.js 22, Go 1.26).

```sh
git clone https://github.com/dshakes/pal.git && cd pal
(cd packages/cli && go build -o "$(go env GOPATH)/bin/pal" ./cmd/pal)
```

<Tabs syncKey="path">
<TabItem label="Try it (no keys)">

The whole platform on Docker, with recorded model answers. Each visitor gets a throwaway workspace that expires after 30 minutes.

```console
$ make demo
…                    # Docker builds and starts the containers (slow the first time)
demo: http://localhost:3001/kiosk
$ make demo-down     # stop it and delete its volumes
```

Next: [Try it: the demo](/docs/start/demo/).

</TabItem>
<TabItem label="Use pal">

Install and pair the two channel bridges first ([BOT-SETUP.md](repo:/blob/master/docs/personal/BOT-SETUP.md)). Then `pal setup` walks you through the rest, checking each step live. Lines in `<…>` depend on you.

```console
$ pal dev            # the control plane and dashboard, on this Mac
$ pal setup
pal setup
────────────────────────────────────────────────

1. Meet pal
   <what pal will touch, then it asks for your consent>

2. Connect channels (checked live)
   ✓ iMessage: connected
   ✓ WhatsApp: connected

3. Learn your voice
   From <n> messages you sent: <register>, <sentence length>, <warmth>

4. Set trust
5. Your people and facts
6. First Brief

You're set.
   Apply later with: pal setup --apply
```

`pal setup` resumes where you left off and never gives consent for you. Next: [How pal works](/docs/pal/), then [Connect your channels](/docs/pal/surfaces/).

</TabItem>
