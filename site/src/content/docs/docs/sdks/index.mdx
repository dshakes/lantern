The **SDKs** wrap the control plane's REST API in typed methods, so you can start runs, hold sessions and script bulk operations from your own code instead of hand-writing HTTP. There are three: **TypeScript** (the fullest, and the only one that also writes agent code), **Python** (async, at management parity with Go) and **Go**. Pick your language in any tab; every tabbed example on the site follows it. For the raw endpoints see [REST API](/docs/reference/api/).

| SDK | Package | Import | Notes |
| --- | --- | --- | --- |
| TypeScript | `@pal-runtime/sdk` | `PalClient` | Event streams, retries, agent authoring (`agent`, `step`) |
| Python | `pal-runtime` | `from pal import PalClient` | Async; runtime context (`ctx.*`) is stubbed |
| Go | `github.com/dshakes/pal/packages/sdk-go` | package `pal` | Retries; no run event stream yet |

Every sample here was checked against the SDK source on `master` (`packages/sdk-ts`, `packages/sdk-python`, `packages/sdk-go`).

## Install

<Aside type="caution" title="Not on a registry yet">
None of the three is published. Install from a checkout. Do not install an SDK from PyPI or npm under a similar name: none of those packages are ours.
</Aside>

<TabItem label="TypeScript" icon="seti:typescript">

( cd packages/sdk-ts && npm install && npm run build )

## Client setup

All three read `PAL_API_KEY` and `PAL_API_URL` when you pass nothing. The built-in default URL is not a live service, so always set `PAL_API_URL` to your own control plane, for example `http://localhost:8080`.

<Tabs syncKey="lang">
<TabItem label="TypeScript" icon="seti:typescript">
```ts
import { PalClient } from "@pal-runtime/sdk";

const client = new PalClient({
  apiKey: process.env.PAL_API_KEY,
  baseUrl: process.env.PAL_API_URL ?? "http://localhost:8080",
});
```
</TabItem>
<TabItem label="Python" icon="seti:python">
```python
from pal import PalClient

# Every request method is async (httpx.AsyncClient underneath).
async with PalClient(
    api_key="...",                    # or PAL_API_KEY
    base_url="http://localhost:8080", # or PAL_API_URL
) as client:
    ...
```
</TabItem>
<TabItem label="Go" icon="seti:go">
```go
import pal "github.com/dshakes/pal/packages/sdk-go"

c := pal.New(
    pal.WithBaseURL("http://localhost:8080"), // or PAL_API_URL
    pal.WithAPIKey(os.Getenv("PAL_API_KEY")),
)
```
</TabItem>
</Tabs>

## Create a run and read the result

<Tabs syncKey="lang">
<TabItem label="TypeScript" icon="seti:typescript">
```ts
import type { Run } from "@pal-runtime/sdk";

const run = (await client.runs.create({
  agent: "research-agent",
  input: { topic: "quantum computing" },
})) as Run;

// Live events until the run ends
for await (const event of client.runs.events(run.id)) {
  console.log(event.kind, event.stepId, event.data);
}

const done = await client.runs.get(run.id);
console.log(done.status, done.output);
```
</TabItem>
<TabItem label="Python" icon="seti:python">
```python
run = await client.runs.create(agent="research-agent", input={"topic": "AI safety"})
print(run.id, run.status)  # queued

async for event in client.runs.events(run.id):
    print(event)

done = await client.runs.get(run.id)
```
</TabItem>
<TabItem label="Go" icon="seti:go">
```go
r, err := c.CreateRun(ctx, pal.RunOptions{
    AgentName: "research-agent",
    Input:     map[string]string{"topic": "quantum computing"},
})
if err != nil {
    log.Fatal(err)
}
done, _ := c.GetRun(ctx, r.ID) // poll: the Go SDK has no event stream yet
fmt.Println(done.Status, string(done.Output), done.CostUsd)
```
</TabItem>
</Tabs>

<details>
<summary>Event kinds you will see on the stream</summary>

`step_started`, `step_completed`, `step_failed`, `tool_call`, `tool_result`, `llm_delta`, `log`, `approval`, `confidence_evaluated` and `end`. The stream closes when the run is `succeeded`, `failed` or `cancelled`. See [Token streaming](/docs/runtime/streaming/).

</details>

## Interactive sessions

<Tabs syncKey="lang">
<TabItem label="TypeScript" icon="seti:typescript">
```ts
const session = await client.sessions.create({ agent: "my-agent" });

for await (const chunk of client.sessions.streamMessage(session.id, {
  content: "What is the capital of France?",
})) {
  if (chunk.type === "delta") process.stdout.write(chunk.delta);
  if (chunk.type === "completed") console.log("\nusage:", chunk.usage);
}

await client.sessions.delete(session.id);
```
</TabItem>
<TabItem label="Python" icon="seti:python">
```python
session = await client.sessions.create(agent="my-agent")
await client.sessions.send_message(session.id, content="What is the capital of France?")
async for event in client.sessions.stream_events(session.id):
    print(event)  # the reply arrives here
await client.sessions.delete(session.id)
```
</TabItem>
<TabItem label="Go" icon="seti:go">
```go
s, _ := c.CreateSession(ctx, "my-agent", nil)
_ = c.SendSessionMessage(ctx, s.ID, "What is the capital of France?")
_ = c.DeleteSession(ctx, s.ID)
```
</TabItem>
</Tabs>

## Errors and retries

<Tabs syncKey="lang">
<TabItem label="TypeScript" icon="seti:typescript">
```ts
import { PalApiError } from "@pal-runtime/sdk";

try {
  await client.runs.create({ agent: "my-agent", input: {} });
} catch (err) {
  if (err instanceof PalApiError && err.status === 402) {
    // a hard-fail budget blocked the run
  }
}
```
</TabItem>
<TabItem label="Python" icon="seti:python">
```python
from pal import PalApiError

try:
    await client.runs.create(agent="my-agent", input={})
except PalApiError as e:
    if e.status == 402:
        ...  # a hard-fail budget blocked the run
```
</TabItem>
<TabItem label="Go" icon="seti:go">
```go
var apiErr *pal.APIError
if errors.As(err, &apiErr) && apiErr.Status == http.StatusPaymentRequired {
    // a hard-fail budget blocked the run
}
```
</TabItem>
</Tabs>

The TypeScript and Go clients retry HTTP `429`, `503` and network errors with full-jitter backoff (TypeScript: 3 attempts, 500 ms base, 4 s cap; Go: `WithMaxRetries`). Other `4xx` and `5xx` are never retried.

## Writing the agent itself

The SDKs above manage agents from outside. Inside an agent bundle, the TypeScript SDK gives you `ctx`: durable steps, LLM calls, tools, memory and connectors. Every `step` is journaled, so a crashed run resumes instead of restarting.

<Aside type="note" title="Python agent code">
The Python runtime context (`ctx.llm`, `ctx.tools`, `ctx.mem` and the rest) is stubbed and raises `NotImplementedError`. Write agent logic in TypeScript for now; use Python for the management API.
</Aside>

```ts
import { agent, step } from "@pal-runtime/sdk";

export default agent<{ query: string }>({
  name: "my-agent",
  model: "auto",
  async run({ input, ctx }) {
    // Durable step: journaled, idempotent, resumable after a crash
    const data = await step("fetch-data", () => ctx.tools.web.search(input.query));

    // Addressed by capability; PAL maps it to a vendor model
    const summary = await step("summarize", () =>
      ctx.llm.complete({
        messages: [{ role: "user", content: `Summarize: ${data}` }],
        capability: "reasoning-small",
      }),
    );
    return { summary };
  },
});
```

<details>
<summary>Parallel fan-out and human approval</summary>

```ts
// Fan out: one journaled step per query
const results = await step.map("search", queries, (q) => ctx.tools.web.search(q));

// Blocks until a human grants or denies; denial or timeout throws
await ctx.approval.request({
  reason: "Send this email to 500 users?",
  expiresAt: "2026-12-01T00:00:00Z",
});
```

</details>

Use capability names (`auto`, `reasoning-large`, `chat-small`, `vision-large`), never a vendor model. See [Models](/docs/build/models/).
