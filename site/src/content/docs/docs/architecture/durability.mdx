## Reference

| Mechanism | Where | Guarantee |
| --- | --- | --- |
| `journal_events` | Postgres, PK `(run_id, seq)` | Ordered, replayable event log |
| Run lease | `run_locks` | One worker per run |
| Recovery sweep | every 30 s (`PAL_RECOVERY_INTERVAL`) | Steals only expired locks |
| `CompletedStep` | workflow interpreter | Completed nodes are skipped on re-drive |
| `claimSideEffect` | before external deliveries | Keyed `run:step:attempt`; no double send |
| Subagent depth | child runs | Capped at 5 |

See also [Durable execution](/docs/runtime/durable-execution/).
