## Reference

- Over a budget or VM quota: **HTTP 402**, before any compute or tokens.
- An eval run worse than its branch baseline: **HTTP 422**.
- Every provider call carries an `Idempotency-Key` derived from `(run_id, step_id, attempt)`.
- Streams are end to end: `GET /v1/runs/{id}/events` flushes per event and tails until the run is terminal.
