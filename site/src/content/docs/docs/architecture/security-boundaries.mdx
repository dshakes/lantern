## Reference

- Internal gRPC ports `:50051`–`:50055` require `x-pal-service-token`; production refuses to start without it.
- A per-VM certificate is refused on every `RuntimeManager` method.
- Broker mode (`PAL_EGRESS_MODE=broker`, Firecracker only): no NIC in the guest; credentials are injected on the host and never enter the VM.
- DLP (ADR 0030) inspects TLS-terminated injecting hosts and plain HTTP only; it is a guard rail and an audit trail, not the boundary.
